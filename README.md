# Naina — personal portfolio

An original responsive portfolio made with HTML and CSS only. No JavaScript, installation, external font downloads, or build step is needed.

## Open in Antigravity
1. Extract this ZIP.
2. Open the `naina-portfolio` folder in Antigravity.
3. Edit `index.html` for content and `style.css` for design.
4. Open `index.html` in your browser to see the site. Refresh after saving edits.

## Personalise before submitting
- Review the personal copy, including two years of JEE Main preparation and entrance-exam achievements. The latest content includes your aviation story, project contribution, hackathons, six years of Kathak, national-level sports, public speaking, food, and travel.
- Optionally add specific sports, event dates, certificates, and project screenshots. No hackathon rankings or awards are claimed.
- GitHub, LinkedIn, and email links are configured.
- Project capabilities reflect your description; check they match the live version you present. The floor plan graphic is a decorative CSS illustration, not a screenshot or interactive viewer.

## How the code works
- Semantic HTML: header, nav, main, section, article, and footer organise the page.
- Anchor links: navigation scrolls to matching section IDs.
- CSS Grid and Flexbox: arrange content across desktop and phone layouts.
- Media queries: adapt the page to smaller screens.
- Native details/summary: expandable project stories without JavaScript.
- :hover and :focus-visible: mouse and keyboard interaction feedback.
- CSS variables: edit the colours at the top of style.css.
- prefers-reduced-motion: respects visitors who prefer less animation.

The site intentionally has no non-working contact form, fake skill percentages, or fabricated awards. The introduction uses typography without a photo area.
